A FEW THINGS TO KNOW

시작하기 전에

코딩을 몰라도 쓸 수 있나요?

원하는 일을 일상적인 말로 요청할 수 있습니다. 파일 변경과 실행 결과를 확인하면서 작은 작업부터 시작해보세요.

어떤 컴퓨터에서 실행되나요?

현재 데스크톱 배포 대상은 Apple silicon(M1 이상) Mac과 macOS 11 이상입니다. Windows 데스크톱 지원은 준비 중입니다. 터미널 버전의 설치 조건은 가이드를 확인하세요.

내 파일은 어디로 전송되나요?

프로젝트와 대화 기록은 내 컴퓨터에 저장됩니다. 요청과 작업에 필요한 내용은 연결한 모델 제공자에게 전송됩니다. Alpine Code 자체 수집 서버는 없습니다.

무료인가요?

Alpine Code 소스는 MIT 라이선스로 공개되어 있습니다. 모델 사용에는 연결한 구독이나 API의 비용이 들 수 있고, 로컬 모델도 연결할 수 있습니다.

작은 아이디어부터 시작해요.
